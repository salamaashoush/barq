`@barqjs/diagram` is barq's whiteboard and diagram package, built on Excalidraw's framework-free element model and its file format: `loadFromBlob`, `restore`, `serializeAsJSON`, `convertToExcalidrawElements` and libraries; canvas and SVG rendering with the dark theme and right-to-left text; `exportToCanvas`, `exportToBlob`, `exportToSvg` and `exportScene`; Excalidraw's fonts loaded by unicode range; Mermaid through `@barqjs/diagram/mermaid`; and `DiagramViewer`, a read-only viewer with pan, zoom, pinch and keyboard navigation that follows the color scheme and renders an SVG snapshot on the server before it hydrates.
